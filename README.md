# StudyFlow PWA starter
Upload all files in this folder to an HTTPS static host, then open the site in Chrome on Android and choose Install app / Add to Home screen if offered.
Calendar now includes a month grid, task dots, selectable dates, a selected-day agenda, completion controls, overdue tasks, and a Move to today action.
Tasks and theme preference are saved in browser storage. Scheduled notifications and Google Calendar sync are not implemented yet.
